# Hypotheses

The hypotheses below are preregistration-style targets for future systematic collection. They are not assumed to be true.

- **H0:** no meaningful left/right asymmetry remains after matching comparable incidents.
- **H1:** incident frequency differs by ideological origin after controlling for country, period, sector and action type.
- **H2:** severity distributions differ by ideological origin.
- **H3:** media and institutional reaction differs for otherwise comparable incidents according to ideological origin.
- **H4:** same-camp ideological boundary policing differs in frequency or severity by camp.
- **H5:** publicly funded organizations participate in some documented pressure events; funding status alone does not imply public funding of the event itself.

Any final report must state which hypotheses are supported, unsupported or unresolved and must include robustness checks using high-confidence ideological attributions only.
