# Pilot v0.1 reference data

This directory contains the initial manually assembled pilot dataset used to validate the research model and pipeline.

It is intentionally versioned because it is small, auditable and part of the project's methodological history. It is not a random or exhaustive sample and must not be used to estimate ideological prevalence.

The import command expects:

- `fact_incidents_v0_1.csv`
- `fact_sources_v0_1.csv`
- `dim_country_v0_1.csv`
- `dim_group_v0_1.csv`
- `bridge_country_group_v0_1.csv`

The original XLSX pilot workbook is also retained here as an archival convenience.
